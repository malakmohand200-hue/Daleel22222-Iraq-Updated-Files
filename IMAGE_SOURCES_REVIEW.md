# Daleel Iraq — image source and licence notes

The food cards now use distinct Iraq-specific Wikimedia Commons file pages rather than reusing one food photo. These are remote Commons file redirects; they are not bundled local image files, so internet access is needed and each redirect should be checked in the browser before release.

Attribution requirement: provide creator, source link, licence link (https://creativecommons.org/licenses/by-sa/4.0/), and indicate any edits. CC BY-SA images may require share-alike for adaptations. Keep this file with the project. Do not treat social media reposts as permission to reuse; use the original source and licence.

IMPORTANT: not all existing landmark images have been converted to local files. Before final deployment, test each image URL on desktop and mobile, verify that the photo depicts the named place, and download/licence-track the approved images into `images/` if the team requires offline/local assets. The Ahmed Awa filename is a candidate and needs browser verification before relying on it.
